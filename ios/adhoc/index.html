iPhone

Versiya __VERSION__ (__BUILD__) · __DATE__
Sənin cihazın
iPhone üçün yüklə
Necə quraşdırmaq olar
  1. Bu səhifəni iPhone-da Safari ilə aç və düyməyə bas.
  2. "Quraşdır" sualına Quraşdır cavabını ver. Tətbiq ana ekrana düşəcək.
  3. Açılmasa: Ayarlar → Ümumi → VPN və Cihaz idarəsi bölməsində sertifikata güvən.

Yalnız qeydiyyatdan keçmiş test telefonlarında işləyir.

Android

Sənin cihazın
Android üçün yüklə (APK)
Necə quraşdırmaq olar
  1. Düyməyə bas, qazan.apk faylı yüklənəcək.
  2. Faylı aç. "Naməlum mənbələr" soruşularsa, brauzerə icazə ver.
  3. Quraşdır bas. Köhnə versiya varsa, üzərinə yenilənir.

Windows — İşletmə

Sənin cihazın
Windows üçün yüklə (ZIP)
Necə quraşdırmaq olar
  1. ZIP faylını yüklə, sağ klik → Hamısını çıxar.
  2. Qovluqda qazan_isletme.exe faylını aç.
  3. "Windows kompüterinizi qorudu" çıxarsa: Ətraflı → Hər halda işə sal.

Kassa və işletmə idarəsi üçündür, müştəri tətbiqi deyil.
